# Yelp 数据集样本

<h2>包含 1001 条 Yelp 商家评论的示例数据集</h2>

![Yelp 数据集标题](https://github.com/bright-cn/Yelp-dataset-samples/blob/main/yelp-datasets.png)

这是一个包含 1000 多条 Yelp 商家评论的 Yelp 数据集样本。该数据集使用 <b>Bright Data API</b> 提取。

<h2>数据集中包含的部分数据点：</h2>

* ```business_id```：商家的唯一标识符
* ```Review_author```：撰写评论的作者或用户
* ```Rating```：评论者给出的评分
* ```Date```：评论发布日期
* ```Content```：评论的文本内容
* ```Review_image```：与评论相关的图片
* ```Reactions```：评论收到的其他用户互动
* ```Replies```：对评论的回复或回应
* ```review_order```：该评论在同一商家所有评论中的顺序
* ```Elite_status```：表示评论作者是否拥有精英会员身份

以及更多内容。

这是“Yelp 商家评论”数据集的示例子集，完整数据集包含超过 <b>2 亿条记录</b>。

<h2>Yelp 数据集有哪些使用场景？</h2>

<h3>1. 消费者情绪分析</h3>
通过分析有关你的企业、竞争对手和行业趋势的评论与反馈，深入了解客户意见。利用这些分析优化产品、改善服务并提供个性化客户体验。这让你能够主动响应客户需求并保持竞争力。

<h3>2. 市场研究与增长机会</h3>
监测商家位置、评分和客户评论的变化，以识别新兴市场趋势和潜在扩张区域。及时掌握行业变化，有助于你主动发现增长机会，并通过数据驱动型决策巩固市场地位。

<h3>3. 使用 B2B 数据进行竞争对手分析</h3>
收集餐厅、家政服务和汽车服务等竞争对手企业的数据，分析其营业时间、位置、客户评论和服务项目。利用这些数据深入了解竞争对手的优势与劣势，从而优化策略并提升自身企业的市场定位。
